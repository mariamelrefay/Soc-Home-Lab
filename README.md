Overview

A hands-on Security Operations Center (SOC) home lab focused on security monitoring, threat detection, and incident investigation using Splunk SIEM and Windows endpoint telemetry.

=>Objectives

1-Collect and analyze Windows security logs.
2-Develop and validate SPL detection queries.
3-Investigate suspicious endpoint activities.
4-Map observed behaviors to MITRE ATT&CK.

=>Lab Environment

1-Splunk Enterprise
2-Windows 10
3-Splunk Universal Forwarder
4-Sysmon
5-Windows Security Logs.

=>Projects
1-LSASS Dumping Detection — In progress
2-Scheduled Task Detection — Planned

=>Methodology

Each investigation documents the objective, data sources, detection logic and findings
